กำลังตรวจ Agent…
วิธีติดตั้ง NHSO Secure SmartCard Agent (ทำครั้งแรกครั้งเดียว) และ API ที่ใช้
  1. เตรียมไฟล์ secureagent-1.2.4 (Production) จาก สปสช. แตกไว้ เช่น C:\NHSOSecureSmartCardAgent (ถ้ามีเวอร์ชันเก่า ให้ uninstall.bat และลบโฟลเดอร์เดิมก่อน)
  2. เปิดไฟล์ userconfig.properties ด้วย Notepad ใส่ TOKEN ของหน่วยบริการ: nhso.service.token=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx แล้วบันทึก
  3. คลิกขวา install.bat → Run as Administrator รอจนเสร็จ (จะมี service ชื่อ NHSOSecureSmartCardAgent ใน Windows Services)
  4. เปิด http://localhost:8189 ต้องเห็นหน้าสถานะ Agent และเครื่องอ่านบัตร
  5. กลับมาที่โปรแกรมนี้ ไฟ AGENT ที่แถบล่างต้องเป็นสีเขียว → เสียบบัตรแล้วกด “อ่านบัตร + ตรวจสิทธิ” ได้เลย
ได้ TOKEN ใหม่: แก้ userconfig.properties แล้วคลิกขวา restart.bat → Run as Administrator · ต้องใช้ proxy: แก้ NHSOSecureSmartCardAgent.xml ก่อนติดตั้ง · port 8189 และ 50204 ต้องว่าง · Agent อยู่เครื่องอื่น: ตั้งที่อยู่ที่แท็บ 08 ตั้งค่า → D
อ่านบัตรแล้วขึ้น PKIX path building failed: JRE ที่มากับ Agent เก่า — ให้ IT อัปเดต JRE 8 (Eclipse Temurin) จาก adoptium.net → Stop service → เปลี่ยนชื่อโฟลเดอร์ jre เดิมเป็น jre_old → วาง jre ใหม่แทน → Start service (แนวทาง สปสช. 11 พ.ย. 2569)
