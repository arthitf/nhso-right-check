03ติดตั้ง & ตั้งค่า

แบบตัวติดตั้ง (Windows)

  1. ดับเบิลคลิก nhso-right-check-windows-setup.exe แล้วกด Next ไปจนจบ (ไม่ต้องใช้สิทธิ Admin)
  2. เปิดโปรแกรมจากไอคอน ตรวจสอบสิทธิ สปสช. บน Desktop หรือ Start Menu
  3. ไปที่แท็บ 07 ตั้งค่า ส่วน B กรอก ระบบ (Production/Test), HCODE, เลขบัตรผู้บันทึก และ TOKEN KEY จากอีเมล สปสช. แล้วกด บันทึกการตั้งค่า (ทำครั้งเดียว อัปเดตเวอร์ชันใหม่ค่าไม่หาย)

แบบแตกไฟล์ใช้ได้เลย (Windows / macOS / Linux)

  1. แตกไฟล์ zip ไว้ในโฟลเดอร์ เช่น Desktop\nhso-right-check
  2. เปิดโปรแกรมแล้วตั้งค่าที่แท็บ 07 ตั้งค่า ได้เลย หรือจะเปลี่ยนชื่อไฟล์ .env.example เป็น .env แล้วแก้ด้วย Notepad ก็ได้ 
    NHSO_ENV=prod                 # prod = ใช้จริง (ค่าเริ่มต้น), test = ทดสอบ
HCODE=xxxxx                   # รหัสหน่วยบริการ 5 หลัก
NHSO_ENDPOINT_TOKEN=xxxxxxxx  # TOKEN KEY ที่ สปสช. ส่งทางอีเมล
RECORDER_PID=xxxxxxxxxxxxx    # เลขบัตรเจ้าหน้าที่ผู้บันทึก
  3. เปิดโปรแกรม
    Windowsดับเบิลคลิก nhso-right-check.exe ถ้า SmartScreen เตือน ให้กด “More info” แล้วกด “Run anyway”
    macOSคลิกขวาที่ nhso-right-check แล้วเลือก Open (ครั้งแรกครั้งเดียว) หรือเปิด Terminal พิมพ์
    xattr -d com.apple.quarantine nhso-right-check && ./nhso-right-check
    Linuxchmod +x nhso-right-check && ./nhso-right-check
  4. โปรแกรมจะเปิดเป็นหน้าต่างของตัวเอง (Windows ใช้ Edge WebView2 ที่มากับ Windows 10/11, macOS ใช้ WebKit) ปิดหน้าต่าง = ปิดโปรแกรม (ถ้าชอบใช้ในเบราว์เซอร์ เปลี่ยนได้ที่แท็บ 07 ตั้งค่า → C การเปิดโปรแกรม โหมดเบราว์เซอร์ปิดโปรแกรมด้วยปุ่ม “ปิดโปรแกรม” ที่แถบล่าง) ถ้าเครื่องไม่มี WebView (เช่น Linux บางรุ่น) จะเปิดในเบราว์เซอร์ที่ http://127.0.0.1:8765 แทน ทำงานในเครื่องตัวเองเท่านั้น

Token ตรวจสอบสิทธิ (SRM)

เสียบบัตร→Login SRM Portal + PIN→กด “คลิกเพื่อเข้าใช้งานระบบ SRM Portal”→token.txt→โปรแกรมอ่านให้เอง

ไฟล์ token อยู่ที่ %USERPROFILE%\SRM Smart Card Single Sign-On\token.txt ไฟล์นี้จะถูกเขียนใหม่ทุกครั้งที่เสียบบัตรแล้ว Login โปรแกรมจะอ่านไฟล์ใหม่ทุกครั้งที่กดตรวจสอบสิทธิ ถ้าหาไฟล์ไม่เจอ ให้ไปที่แท็บ 07 ตั้งค่า ส่วน A แล้ววาง token เองได้ ถ้าโปรแกรมเตือนว่า token เก่า ให้เสียบบัตร Login SRM Portal ใหม่

ไฟ SRM / ENDPOINT ที่แถบล่างของโปรแกรม ถ้าเป็นสีเขียว แปลว่าตั้งค่า token ครบแล้ว

04วิธีใช้งาน

ข้อควรระวังการใช้งาน API: การตรวจสอบสิทธิผ่าน API ใช้โควตาของหน่วยบริการ การตรวจจำนวนมากหรือตรวจซ้ำซ้อน อาจทำให้โควตาหมดและกระทบงานบริการ หากต้องตรวจสอบสิทธิเป็นกลุ่ม แนะนำใช้ SRM Portal → ตรวจสอบสิทธิแบบกลุ่ม

01 ตรวจสอบสิทธิ

  1. กรอกเลขบัตรประชาชน 13 หลัก โปรแกรมตรวจ check digit ให้ด้วย
  2. กด ตรวจสอบสิทธิ จะเห็นสิทธิหลัก (UCS / OFC / SSS / LGO …) สิทธิย่อย หน่วยบริการประจำ หน่วยปฐมภูมิ หน่วยรับส่งต่อ และสถานะเสียชีวิต
  3. กด ไปปิดสิทธิคนนี้ → เพื่อนำเลขบัตรและสิทธิไปกรอกในหน้าปิดสิทธิให้อัตโนมัติ
  4. กด ▸ ดูข้อมูลทั้งหมดที่ สปสช. ส่งกลับ เพื่อดูทุกค่าเป็นตารางภาษาไทย แยกการ์ดตามสิทธิแต่ละกองทุน
  5. ถ้าตรวจคนเดิมซ้ำภายใน 10 นาที โปรแกรมจะใช้ผลเดิมเพื่อประหยัดโควตา (กด ตรวจใหม่จาก สปสช. ได้ถ้าจำเป็น) แถบล่างจะแสดงจำนวนครั้งที่ตรวจวันนี้

02 ตรวจแบบกลุ่ม

API ของ สปสช. ตรวจได้ครั้งละ 1 คน แท็บนี้จึงวนตรวจให้ทีละคนพร้อมตัวป้องกันโควตา — ทุกคนในรายชื่อนับเป็น 1 ครั้งของโควตาหน่วยบริการ รายชื่อจำนวนมากยังแนะนำใช้ SRM Portal

  1. ลากไฟล์ Excel (.xlsx) / CSV / TXT มาวาง หรือวางเลขบัตรในช่องข้อความ (คัดลอกทั้งคอลัมน์จาก Excel ได้) โปรแกรมหาเลข 13 หลักทุกช่องให้เอง ไม่ต้องจัดคอลัมน์
  2. กด อ่านรายชื่อ — ยังไม่เรียก API จะสรุปให้ดูก่อน: จำนวนคน, เลขซ้ำที่ตัดออก, เลขผิด check digit (ไม่ตรวจ), คนที่ใช้ผลเดิมได้ และโควตาที่จะใช้ กับเวลาโดยประมาณ
  3. กด เริ่มตรวจ แล้วยืนยัน ระหว่างตรวจกด หยุด ได้ตลอด และกด ตรวจต่อ เพื่อทำต่อจากคนถัดไป
  4. โปรแกรมหยุดพักเองเมื่อ สปสช. ตอบ 429 (เรียกถี่เกินไป), token หมดอายุ (เสียบบัตร Login SRM ใหม่แล้วกดตรวจต่อ) หรือเชื่อมต่อไม่ได้
  5. กด บันทึกเป็น Excel ไฟล์จะอยู่ในโฟลเดอร์ Downloads ชื่อ ผลตรวจสิทธิกลุ่ม_วันที่_เวลา.xlsx เลขบัตรเป็นข้อความเต็ม 13 หลัก (ไม่กลายเป็น 1.1E+12) มีตัวกรองที่หัวตาราง กดเปิดไฟล์หรือเปิดโฟลเดอร์จากโปรแกรมได้เลย
เกิน 300 คน (ค่า BATCH_LIMIT) โปรแกรมจะเตือนให้ใช้ SRM Portal ก่อน ถ้าจำเป็นต้องใช้ API ต้องกดยืนยันอีกครั้ง · ไฟล์ผลตรวจมีข้อมูลส่วนบุคคล ลบเมื่อใช้งานเสร็จ

03 ปิดสิทธิ

  1. กรอก รหัสบริการ (เช่น PG0060001), ค่าบริการที่เบิกได้, ค่าบริการที่เบิกไม่ได้, วันเวลาที่รับบริการ และ VN
  2. กด ตรวจข้อมูลก่อนส่ง เพื่อดูข้อมูลที่จะส่ง (ยังไม่ส่งไป สปสช.)
  3. กด กดปิดสิทธิ แล้วตรวจข้อมูลในหน้าต่างยืนยัน จากนั้นกด กดปิดสิทธิ อีกครั้ง ถ้าเป็น Production ต้องพิมพ์ YES ก่อน
  4. ถ้าสำเร็จจะได้ authenCode (กดคัดลอกได้) พร้อม seq และ transactionId ทุกรายการถูกบันทึกในแท็บประวัติ
ถ้าขึ้น timeout ตอนปิดสิทธิ อย่าเพิ่งกดซ้ำ เพราะฝั่ง สปสช. อาจบันทึกไปแล้ว ให้ตรวจสอบก่อน
ถ้าเคยปิดสิทธิสำเร็จแล้ว (คนเดิม รหัสบริการเดิม วันเดียวกัน) โปรแกรมจะเตือนและให้ยืนยันก่อนส่งซ้ำ

04 ยกเลิกปิดสิทธิ

ใส่ transactionId แล้วกด กดยกเลิกปิดสิทธิ ถ้าไม่ใส่ seq โปรแกรมจะหาจากประวัติให้เอง (ระบบส่ง paymentStatus = CANCEL)

05 ประวัติ

แสดง 100 รายการล่าสุด ข้อมูลเก็บในไฟล์ nhso_right_check_log.sqlite3 ในเครื่อง เลขบัตรบนหน้าจอจะถูกปิดบางส่วนไว้

06 ตารางสิทธิ

ตารางรหัสสิทธิ (vr_l_right) 277 รหัส ใช้ค้นหาว่ารหัสแต่ละตัวคือสิทธิอะไร (เช่น UCS, WEL, OFC, SSS, BKK, E45) และอยู่ในกลุ่มสิทธิหลักกลุ่มไหน (U, C, S, L, B, E …) หน้าตรวจสอบสิทธิจะแสดงชื่อสิทธิกับกลุ่มให้อัตโนมัติ และช่อง “สิทธิ” ในหน้าปิดสิทธิจะมีรายการให้เลือก
