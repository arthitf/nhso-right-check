ออกแบบมาเพื่อตรวจสอบสิทธิอย่างเดียว ไม่ปิดสิทธิยืนยันตัวตน + ปิดสิทธิ ณ จุดบริการ ด้วยบัตรประชาชนจริงของผู้ป่วยปิดสิทธิจากระบบของหน่วยบริการ (HIS) โดยไม่ต้องเสียบบัตร — ส่งข้อมูลการเข้ารับบริการพร้อมยอดเบิกได้/เบิกไม่ได้
ใครใช้ / ที่ไหนเจ้าหน้าที่เวชระเบียน/การเงิน ตรวจก่อนให้บริการ หรือตรวจรายชื่อผู้ป่วยเสียบบัตรเองที่ตู้ (KIOSK) หรือเจ้าหน้าที่รับบัตรมาเสียบแล้วปิดสิทธิเจ้าหน้าที่ / ระบบ HIS ของหน่วยบริการ เช่น ช่วงการเงินหรือหลังให้บริการ ใช้เลขบัตรผู้ป่วย
ต้องมีบัตรผู้ป่วยไหมไม่ต้อง (ใช้เลขบัตร)ต้องเสียบบัตรไม่ต้อง (ใช้เลขบัตร)
ยืนยันตัวตนระบบด้วยSRM token จากบัตรเจ้าหน้าที่ (Login SRM Portal วันละครั้ง)TOKEN ของหน่วยบริการ ตั้งในตัว Agent (userconfig.properties)TOKEN KEY ของหน่วยบริการ (ผูกกับ HCODE)
ข้อมูลสิทธิที่ได้สิทธิ ณ วันที่ตรวจ ครบทุกกองทุน (สิทธิหลัก/ย่อย หน่วยบริการ 3 ระดับ จังหวัด หน่วยงานต้นสังกัด)ได้มากับการอ่านบัตร: ข้อมูลบัตร รูปหน้าบัตร สิทธิหลัก/ย่อย หน่วยบริการ 3 ระดับ และประเภทบริการที่คนนี้ใช้สิทธิได้ (claimTypes)มีแฟ้มตรวจสอบสถานะบุคคล (RealPerson) คืนสิทธิหลัก/ย่อย หน่วยบริการ จังหวัด paidModel — โปรแกรมนี้ใช้ ① หาสิทธิก่อนส่งแทน

โควตานับทุกครั้งที่ตรวจ — ตรวจเยอะใช้ SRM Portal แบบกลุ่มตามการใช้งานจริงที่จุดบริการตามรายการที่ส่งเบิก

① SRM — ตรวจสอบสิทธิ

  • เส้นที่ใช้: GET srm.nhso.go.th/api/ucws/v1/right-search?pid=… (แทน API ucws เดิมที่ยุติ 15 ม.ค. 2570)
  • ใช้เมื่อ: อยากรู้ว่าคนนี้มีสิทธิอะไร หน่วยบริการประจำที่ไหน ยังมีชีวิตอยู่ไหม — ไม่ได้ปิดสิทธิ ไม่เกิดรายการเบิก
  • ระวัง: ทุกการตรวจนับโควตาหน่วยบริการ โปรแกรมจึงใช้ผลเดิมถ้าตรวจคนเดิมภายใน 10 นาที และแนะนำ SRM Portal → ตรวจสอบสิทธิแบบกลุ่ม สำหรับรายชื่อจำนวนมาก

② NHSO Secure SmartCard Agent — เสียบบัตร ยืนยันเข้ารับบริการ / ปิดสิทธิ

  • ออกแบบมาให้: ผู้ป่วยเสียบบัตรประชาชน (หรือเจ้าหน้าที่รับบัตรมาเสียบ) แล้วปิดสิทธิได้ทันทีที่จุดบริการ — เป็นการยืนยันว่าเจ้าของบัตรมารับบริการจริง
  • ลำดับ: GET /api/smartcard/read (อ่านบัตร + ตรวจสิทธิ ได้ correlationId และ claimTypes) → POST /api/nhso-service/save-endpoint (ปิดสิทธิ ส่ง correlationId + claimType + ค่าบริการ) → ได้ authenCode
  • ตัวช่วย: GET /api/nhso-service/latest-authen-code/{pid} ดู authen code ล่าสุดที่หน่วยบริการเคยขอ (เช็คหลัง timeout ก่อนส่งซ้ำ) · GET /api/smartcard/read-card-only อ่านบัตรอย่างเดียวตอนต่อ สปสช. ไม่ได้
  • ข้อดี: ไม่ต้องใช้ SRM token, ได้รายการประเภทบริการที่ใช้สิทธิได้จริงจาก สปสช., ได้รูปหน้าบัตรไว้ยืนยันตัวตน · ข้อจำกัด: ต้องติดตั้ง Agent บน Windows และมีเครื่องอ่านบัตร

③ NHSO ENDPOINT for Single Claim — ปิดสิทธิจากระบบหน่วยบริการ (ไม่ต้องเสียบบัตร)

  • ออกแบบมาให้: ระบบของหน่วยบริการ (HIS) ยืนยันการเข้ารับบริการและปิดสิทธิด้วยเลขบัตร โดยไม่ต้องเสียบบัตร ส่งยอดเบิกได้/เบิกไม่ได้ไปพร้อมกัน
  • เส้นที่ใช้: ปิดสิทธิ (แฟ้ม 6 → 7) ส่ง HCODE, สิทธิ (mainInsclCode), รหัสบริการ, ค่าบริการทั้งหมด/เบิกได้/เบิกไม่ได้, วันเวลารับบริการ, transactionId → ได้ seq + authenCode · ยกเลิก (แฟ้ม 8 → 9) ด้วย seq + transactionId
  • ข้อมูลสิทธิ: ในชุดเดียวกันมีแฟ้ม 4/5 ตรวจสอบสถานะบุคคล (RealPerson) คืนสิทธิหลัก/ย่อย หน่วยบริการ จังหวัด paidModel — โปรแกรมนี้ใช้ ① ตรวจสิทธิก่อนเพื่อเติม mainInsclCode ให้อัตโนมัติ
  • ระวัง: เป็นรายการเบิกจริง ตรวจข้อมูลก่อนส่งทุกครั้ง โปรแกรมกันส่งซ้ำ (คนเดิม บริการเดิม วันเดียวกัน) และใน Production ต้องพิมพ์ YES
สรุปการเลือกใช้: แค่อยากรู้สิทธิ → ① · ผู้ป่วยอยู่ตรงหน้าและมีบัตร → ② เสียบบัตรปิดสิทธิ · ปิดสิทธิจากระบบหน่วยบริการด้วยเลขบัตร (ไม่ต้องเสียบบัตร) → ③

04ติดตั้ง & ตั้งค่า

แบบตัวติดตั้ง (Windows)

  1. ดับเบิลคลิก nhso-right-check-windows-setup.exe แล้วกด Next ไปจนจบ (ไม่ต้องใช้สิทธิ Admin)
  2. เปิดโปรแกรมจากไอคอน ตรวจสอบสิทธิ สปสช. บน Desktop หรือ Start Menu
  3. ไปที่แท็บ 08 ตั้งค่า ส่วน B กรอก ระบบ (ค่าเริ่มต้น Production), HCODE, เลขบัตรผู้บันทึก และ TOKEN KEY จากอีเมล สปสช. แล้วกด บันทึกการตั้งค่า (ทำครั้งเดียว อัปเดตเวอร์ชันใหม่ค่าไม่หาย)

แบบแตกไฟล์ใช้ได้เลย (Windows / macOS / Linux)

  1. แตกไฟล์ zip ไว้ในโฟลเดอร์ เช่น Desktop\nhso-right-check
  2. เปิดโปรแกรมแล้วตั้งค่าที่แท็บ 08 ตั้งค่า ได้เลย หรือจะเปลี่ยนชื่อไฟล์ .env.example เป็น .env แล้วแก้ด้วย Notepad ก็ได้ 
    NHSO_ENV=prod                 # prod = ใช้จริง (ค่าเริ่มต้น), test = ทดสอบ
HCODE=xxxxx                   # รหัสหน่วยบริการ 5 หลัก
NHSO_ENDPOINT_TOKEN=xxxxxxxx  # TOKEN KEY ที่ สปสช. ส่งทางอีเมล
RECORDER_PID=xxxxxxxxxxxxx    # เลขบัตรเจ้าหน้าที่ผู้บันทึก
  3. เปิดโปรแกรม
    Windowsดับเบิลคลิก nhso-right-check.exe (เปิดเป็นหน้าต่างเดียว ไม่มีหน้าต่างดำ) ถ้า SmartScreen เตือน ให้กด “More info” แล้วกด “Run anyway”
    macOSลาก nhso-right-check.app ไปไว้ใน Applications แล้วคลิกขวา → Open (ครั้งแรกครั้งเดียว) หรือเปิด Terminal พิมพ์
    xattr -dr com.apple.quarantine nhso-right-check.app
    ค่าตั้งและประวัติเก็บที่ ~/Library/Application Support/nhso-right-check
    Linuxchmod +x nhso-right-check && ./nhso-right-check
  4. โปรแกรมจะเปิดเป็นหน้าต่างของตัวเอง (Windows ใช้ Edge WebView2 ที่มากับ Windows 10/11, macOS ใช้ WebKit) ปิดหน้าต่าง = ปิดโปรแกรม (ถ้าชอบใช้ในเบราว์เซอร์ เปลี่ยนได้ที่แท็บ 08 ตั้งค่า → C การเปิดโปรแกรม โหมดเบราว์เซอร์ปิดโปรแกรมด้วยปุ่ม “ปิดโปรแกรม” ที่แถบล่าง) ถ้าเครื่องไม่มี WebView (เช่น Linux บางรุ่น) จะเปิดในเบราว์เซอร์ที่ http://127.0.0.1:8765 แทน ทำงานในเครื่องตัวเองเท่านั้น

Token ตรวจสอบสิทธิ (SRM)

เสียบบัตร→Login SRM Portal + PIN→กด “คลิกเพื่อเข้าใช้งานระบบ SRM Portal”→token.txt→โปรแกรมอ่านให้เอง

ไฟล์ token อยู่ที่ %USERPROFILE%\SRM Smart Card Single Sign-On\token.txt ไฟล์นี้จะถูกเขียนใหม่ทุกครั้งที่เสียบบัตรแล้ว Login โปรแกรมจะอ่านไฟล์ใหม่ทุกครั้งที่กดตรวจสอบสิทธิ ถ้าหาไฟล์ไม่เจอ ให้ไปที่แท็บ 08 ตั้งค่า ส่วน A แล้ววางเนื้อหาทั้งไฟล์ token.txt ตามที่เห็น (มีทั้งบรรทัด access-token=… และ refresh-token=…) โปรแกรมแยกให้เอง

  • อายุ token: access token ใช้ได้ประมาณ 30 นาที โปรแกรมต่ออายุให้เองด้วย refresh token ซึ่งใช้ได้ประมาณ 24 ชั่วโมง ในทางปฏิบัติคือเสียบบัตร Login SRM Portal วันละครั้ง ถ้า token เก่าเกิน 24 ชั่วโมง โปรแกรมจะเตือน
  • Production เท่านั้น: token จาก SRM Portal ตัวจริงใช้กับ Test Zone ไม่ได้ ถ้าขึ้น “token ไม่ถูกต้อง” ให้ดูว่าแท็บ 08 ตั้งค่าเป็น Production หรือไม่
ห้ามส่ง token ให้ผู้อื่น (ทั้งทางแชท อีเมล หรือภาพหน้าจอ) token ใช้แทนตัวตนของเจ้าของบัตรได้ ถ้าเผลอส่งไปแล้ว ให้ Logout SRM Portal เพื่อยกเลิก
ไฟ SRM / ENDPOINT ที่แถบล่างของโปรแกรม ถ้าเป็นสีเขียว แปลว่าตั้งค่า token ครบแล้ว

05วิธีใช้งาน

ข้อควรระวังการใช้งาน API: การตรวจสอบสิทธิผ่าน API ใช้โควตาของหน่วยบริการ การตรวจจำนวนมากหรือตรวจซ้ำซ้อน อาจทำให้โควตาหมดและกระทบงานบริการ หากต้องตรวจสอบสิทธิเป็นกลุ่ม แนะนำใช้ SRM Portal → ตรวจสอบสิทธิแบบกลุ่ม

01 ตรวจสอบสิทธิ

  1. กรอกเลขบัตรประชาชน 13 หลัก โปรแกรมตรวจ check digit ให้ด้วย
  2. กด ตรวจสอบสิทธิ จะเห็นสิทธิหลัก (UCS / OFC / SSS / LGO …) พร้อมชื่อและกลุ่มสิทธิ, ชื่อ-สกุล, เลขบัตรเต็ม, สิทธิย่อย, สิทธิอื่นที่มี, หน่วยบริการประจำ / ปฐมภูมิ / รับส่งต่อ และสถานะเสียชีวิต
  3. กด ไปปิดสิทธิคนนี้ → เพื่อนำเลขบัตรและสิทธิไปกรอกในหน้าปิดสิทธิให้อัตโนมัติ
  4. กด ▸ ดูข้อมูลทั้งหมดที่ สปสช. ส่งกลับ เพื่อดูทุกค่าเป็นตารางภาษาไทย แยกการ์ดตามสิทธิแต่ละกองทุน (สัญชาติ, เพศ, วันที่เปลี่ยนแปลงสิทธิ, วันเริ่ม/หมดอายุสิทธิ, รูปแบบการจ่ายเงิน, จังหวัดที่ลงทะเบียน, หน่วยงานต้นสังกัดและความสัมพันธ์, เลขบัตรสิทธิ)
  5. API ตรวจสอบสิทธิของ สปสช. ส่งกลับเฉพาะสิทธิ ณ วันที่ตรวจสอบ ไม่มีประวัติสิทธิย้อนหลัง (มีแค่ “วันที่เปลี่ยนแปลงสิทธิ” ล่าสุดของแต่ละกองทุน)
  6. ถ้าตรวจคนเดิมซ้ำภายใน 10 นาที โปรแกรมจะใช้ผลเดิมเพื่อประหยัดโควตา (กด ตรวจใหม่จาก สปสช. ได้ถ้าจำเป็น) แถบล่างจะแสดงจำนวนครั้งที่ตรวจวันนี้

02 เสียบบัตร (NHSO Secure SmartCard Agent)

ผู้ป่วยเสียบบัตรประชาชน → อ่านบัตร + ตรวจสิทธิ → ปิดสิทธิ ในหน้าเดียว ใช้ NHSO Secure SmartCard Agent ของ สปสช. ที่ติดตั้งในเครื่อง (Windows) — ไม่ต้องใช้ SRM token เพราะ Agent ใช้ TOKEN ของหน่วยบริการเอง

ติดตั้ง Agent ครั้งแรก (ทำครั้งเดียว) — ขั้นตอนนี้มีอยู่ในโปรแกรมด้วย ที่กล่อง “วิธีติดตั้ง NHSO Secure SmartCard Agent” ในแท็บ 02 (ถ้ายังไม่พบ Agent กล่องจะเปิดขึ้นมาเอง)

  1. เตรียมไฟล์ secureagent-1.2.4 (Production) จาก สปสช. แตกไว้ เช่น C:\NHSOSecureSmartCardAgent — ถ้ามีเวอร์ชันเก่า ให้รัน uninstall.bat และลบโฟลเดอร์เดิมก่อน
  2. เปิด userconfig.properties ด้วย Notepad ใส่ TOKEN ของหน่วยบริการ nhso.service.token=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx แล้วบันทึก
  3. คลิกขวา install.bat → Run as Administrator รอจนเสร็จ (Windows Services จะมี NHSOSecureSmartCardAgent)
  4. เปิด http://localhost:8189 ต้องเห็นหน้าสถานะ Agent และเครื่องอ่านบัตร
  5. ในโปรแกรมเรา ไฟ AGENT ที่แถบล่างต้องเป็นสีเขียว (ถ้า Agent อยู่เครื่องอื่น ตั้งที่อยู่ได้ที่แท็บ 08 ตั้งค่า → D)

ได้ TOKEN ใหม่: แก้ userconfig.properties แล้วคลิกขวา restart.bat → Run as Administrator · ใช้ proxy: แก้ NHSOSecureSmartCardAgent.xml ก่อนติดตั้ง · port 8189 และ 50204 ต้องว่าง

ใช้งาน

  1. ให้ผู้ป่วยเสียบบัตร แล้วกด อ่านบัตร + ตรวจสิทธิ จะเห็นรูปหน้าบัตร ชื่อ เลขบัตร สิทธิ (พร้อมชื่อและกลุ่มจากตาราง vr_l_right) และหน่วยบริการ
  2. เลือก ประเภทบริการ — รายการนี้ สปสช. ส่งมาตามสิทธิของผู้ป่วยคนนั้น (มีทั้งรหัสและชื่อบริการ) กรอกค่าบริการ วันเวลาที่เบิก VN และเบอร์มือถือ (ถ้ามี)
  3. กด ตรวจข้อมูลก่อนส่ง แล้ว กดปิดสิทธิ → ได้ authenCode + seq บันทึกในแท็บประวัติ (รายการ AGENT_CLAIM)
  4. ปุ่ม authen code ล่าสุดของคนนี้ ใช้ตรวจว่าเคยขอ authen code กับหน่วยบริการแล้วหรือยัง (เช่นหลัง timeout) · ปุ่ม อ่านบัตรอย่างเดียว ใช้ตอนเชื่อมต่อ สปสช. ไม่ได้ (ปิดสิทธิไม่ได้)

ปุ่มแต่ละปุ่มเรียก API ของ Agent เส้นไหน (แสดงไว้ในโปรแกรมด้วย ใต้ปุ่ม และในกล่องวิธีติดตั้ง)

03 ตรวจแบบกลุ่ม

API ของ สปสช. ตรวจได้ครั้งละ 1 คน แท็บนี้จึงวนตรวจให้ทีละคนพร้อมตัวป้องกันโควตา — ทุกคนในรายชื่อนับเป็น 1 ครั้งของโควตาหน่วยบริการ รายชื่อจำนวนมากยังแนะนำใช้ SRM Portal

  1. ลากไฟล์ Excel (.xlsx) / CSV / TXT มาวาง หรือวางเลขบัตรในช่องข้อความ (คัดลอกทั้งคอลัมน์จาก Excel ได้) โปรแกรมหาเลข 13 หลักทุกช่องให้เอง ไม่ต้องจัดคอลัมน์
  2. กด อ่านรายชื่อ — ยังไม่เรียก API จะสรุปให้ดูก่อน: จำนวนคน, เลขซ้ำที่ตัดออก, เลขผิด check digit (ไม่ตรวจ), คนที่ใช้ผลเดิมได้ และโควตาที่จะใช้ กับเวลาโดยประมาณ
  3. กด เริ่มตรวจ แล้วยืนยัน ระหว่างตรวจกด หยุด ได้ตลอด และกด ตรวจต่อ เพื่อทำต่อจากคนถัดไป
  4. โปรแกรมหยุดพักเองเมื่อ สปสช. ตอบ 429 (เรียกถี่เกินไป), token หมดอายุ (เสียบบัตร Login SRM ใหม่แล้วกดตรวจต่อ) หรือเชื่อมต่อไม่ได้
  5. กด บันทึกเป็น Excel ไฟล์จะอยู่ในโฟลเดอร์ Downloads ชื่อ ผลตรวจสิทธิกลุ่ม_วันที่_เวลา.xlsx เลขบัตรเป็นข้อความเต็ม 13 หลัก (ไม่กลายเป็น 1.1E+12) มีตัวกรองที่หัวตาราง กดเปิดไฟล์หรือเปิดโฟลเดอร์จากโปรแกรมได้เลย
เกิน 300 คน (ค่า BATCH_LIMIT) โปรแกรมจะเตือนให้ใช้ SRM Portal ก่อน ถ้าจำเป็นต้องใช้ API ต้องกดยืนยันอีกครั้ง · ไฟล์ผลตรวจมีข้อมูลส่วนบุคคล ลบเมื่อใช้งานเสร็จ

04 ปิดสิทธิ (กรอกเลขบัตร · NHSO ENDPOINT)

  1. เลือก รหัสบริการ จากรายการ (มีชื่อบริการกำกับ หรือเลือก “อื่นๆ” แล้วพิมพ์รหัสเอง), ค่าบริการที่เบิกได้, ค่าบริการที่เบิกไม่ได้, วันเวลาที่รับบริการ และ VN
  2. กด ตรวจข้อมูลก่อนส่ง เพื่อดูข้อมูลที่จะส่ง (ยังไม่ส่งไป สปสช.)
  3. กด กดปิดสิทธิ แล้วตรวจข้อมูลในหน้าต่างยืนยัน จากนั้นกด กดปิดสิทธิ อีกครั้ง ถ้าเป็น Production ต้องพิมพ์ YES ก่อน
  4. ถ้าสำเร็จจะได้ authenCode (กดคัดลอกได้) พร้อม seq และ transactionId ทุกรายการถูกบันทึกในแท็บประวัติ
ถ้าขึ้น timeout ตอนปิดสิทธิ อย่าเพิ่งกดซ้ำ เพราะฝั่ง สปสช. อาจบันทึกไปแล้ว ให้ตรวจสอบก่อน
ถ้าเคยปิดสิทธิสำเร็จแล้ว (คนเดิม รหัสบริการเดิม วันเดียวกัน) โปรแกรมจะเตือนและให้ยืนยันก่อนส่งซ้ำ
รหัสบริการความหมาย (ตามเอกสาร NHSO ENDPOINT v8.0)
PG0060001เข้ารับบริการรักษาทั่วไป (OPD / IPD / PP) — ค่าเริ่มต้น
PG0130001บริการฟอกเลือดด้วยเครื่องไตเทียม (HD)
PG0150001บริการดูแลอาการเจ็บป่วยเบื้องต้น (Common illnesses)
PG0120001UCEP PLUS (ผู้ป่วยกลุ่มอาการสีเหลืองและสีแดง)
PG0110001Self Isolation

เอกสารระบุว่ามีรหัสอื่นตามแฟ้มมาตรฐานบริการ (Service Authen) ของ สปสช. ด้วย — พิมพ์รหัสเองได้ ตรวจรหัสให้ถูกก่อนส่ง

05 ยกเลิกปิดสิทธิ

ใส่ transactionId แล้วกด กดยกเลิกปิดสิทธิ ถ้าไม่ใส่ seq โปรแกรมจะหาจากประวัติให้เอง (ระบบส่ง paymentStatus = CANCEL)

06 ประวัติ

แสดง 100 รายการล่าสุด ข้อมูลเก็บในไฟล์ nhso_right_check_log.sqlite3 ในเครื่อง เลขบัตรในแท็บประวัติจะถูกปิดบางส่วนไว้ (หน้าตรวจสอบสิทธิแสดงเลขเต็ม)

07 ตารางสิทธิ

ตารางรหัสสิทธิ (vr_l_right) 277 รหัส ใช้ค้นหาว่ารหัสแต่ละตัวคือสิทธิอะไร (เช่น UCS, WEL, OFC, SSS, BKK, E45) และอยู่ในกลุ่มสิทธิหลักกลุ่มไหน (U, C, S, L, B, E …) หน้าตรวจสอบสิทธิจะแสดงชื่อสิทธิกับกลุ่มให้อัตโนมัติ และช่อง “สิทธิ” ในหน้าปิดสิทธิจะมีรายการให้เลือก

06ทำทีละหลายคน (Command line)

ข้อควรระวังการใช้งาน API: การตรวจสอบสิทธิผ่าน API ใช้โควตาของหน่วยบริการ การตรวจจำนวนมากหรือตรวจซ้ำซ้อน อาจทำให้โควตาหมดและกระทบงานบริการ หากต้องตรวจสอบสิทธิเป็นกลุ่ม แนะนำใช้ SRM Portal → ตรวจสอบสิทธิแบบกลุ่ม

เตรียมไฟล์ CSV (ดูตัวอย่างในโฟลเดอร์ examples) แล้วเปิด Command Prompt / Terminal ในโฟลเดอร์โปรแกรม (Windows ใช้ไฟล์ nhso-right-check-cli.exe ซึ่งติดตั้งมาพร้อมกัน — ตัว nhso-right-check.exe เป็นแบบหน้าต่างอย่างเดียว) โปรแกรมจะตัดเลขบัตรซ้ำออกให้ และถ้ารายชื่อมีจำนวนมาก จะให้ยืนยันก่อน (--allow-large)

401 / token หมดอายุเสียบบัตร Login ใหม่ (โปรแกรมจะอ่านไฟล์ใหม่และลอง refresh ให้อัตโนมัติ)
token ไม่ถูกต้อง ทั้งที่เพิ่ง Loginดูว่าแท็บ 08 ตั้งค่า ตั้งระบบเป็น Production (token ตัวจริงใช้กับ Test Zone ไม่ได้)
อยากดูประวัติสิทธิย้อนหลังAPI ส่งกลับเฉพาะสิทธิ ณ วันที่ตรวจ ดูประวัติย้อนหลังได้ที่ SRM Portal
404 ไม่พบข้อมูลตรวจเลขบัตรประชาชนอีกครั้ง
dataError: Invalid TokenTOKEN KEY ใน .env ไม่ถูกต้อง หรือไม่ใช่ของ HCODE นี้
พบการบันทึก transactionId ซ้ำรายการนี้เคยส่งแล้ว ให้ดูในแท็บประวัติ
serviceDateTime ไม่เกินวันเวลาปัจจุบันตรวจวันที่ ต้องเป็นปี ค.ศ. และห้ามเป็นเวลาในอนาคต
เชื่อมต่อไม่ได้ / ProxyErrorตรวจอินเทอร์เน็ต, proxy หรือ VPN ของหน่วยงาน
HTTP 429 / เรียกใช้งานมากเกินไปหยุดสักพัก และใช้ SRM Portal → ตรวจสอบสิทธิแบบกลุ่มสำหรับรายชื่อจำนวนมาก
ไม่พบ Agent ที่ localhost:8189ตรวจ Windows Services ว่ามี NHSOSecureSmartCardAgent และกำลังทำงาน หรือรัน start-no-service.bat (เลือก prod) · port 8189 / 50204 ต้องว่าง
Agent ขึ้นหน้า Sign in / ยังไม่ได้ตั้ง TOKENใส่ TOKEN ใน userconfig.properties ของ Agent แล้วรัน restart.bat (Run as Administrator)
ยังไม่ได้เสียบบัตร / ไม่พบเครื่องอ่านบัตรเสียบบัตรให้สนิท ตรวจสาย USB และไดรเวอร์เครื่องอ่านบัตร
Port 8765 ไม่ว่างโปรแกรมจะหา port ถัดไปให้เอง (8766, 8767 …) — คนละ port กับ Agent (8189)

ความปลอดภัย & ข้อมูลส่วนบุคคล

  • โปรแกรมเปิดเฉพาะในเครื่องตัวเอง (127.0.0.1) เครื่องอื่นในเครือข่ายเข้าไม่ได้
  • ไฟล์ .env, token และไฟล์ประวัติ .sqlite3 เป็นความลับ ห้ามส่งต่อหรืออัปขึ้น cloud
  • ไฟล์ผลลัพธ์ (Excel / CSV) มีข้อมูลส่วนบุคคล (PDPA) ลบเมื่อใช้งานเสร็จ
  • ห้ามส่ง token / TOKEN KEY ให้ผู้อื่น และระวังภาพหน้าจอที่มีเลขบัตรเต็ม
